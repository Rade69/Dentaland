# DENT-003 — Plan prije izmjene (MEDIUM)

**Cilj:** Servisni sloj (provjera preklapanja termina) koji desktop GUI koristi
umjesto `FakeStore`, uz minimalan izbor doktora u GUI. Drop-in zamjena istog
interfejsa (`create/get/all/move/services`), field-name prevod fake ↔ model.

**Pogođeno:** `src/dentaland/services/**` (novo), `desktop/app.py`,
`desktop/views/main_window.py`, `desktop/views/week_view.py`,
`tests/test_services.py` (novo), `agent_reports/**`.

**Plan:**
1. `src/dentaland/services/booking.py` — `AppointmentDTO`/`DoctorDTO` (plain
   dataclass, ne SQLAlchemy objekti), `OverlapError`, `AppointmentService`
   (CRUD + provjera preklapanja po `doctor_id` + `status==SCHEDULED` +
   `start_time < end AND end_time > start`), `ensure_seed_data()` (3 doktora +
   5 usluga), i `AppointmentService.from_sqlite(path)` factory (engine, seed,
   default prvi doktor).
2. `src/dentaland/services/__init__.py` — re-export.
3. `desktop/app.py` — `AppointmentService.from_sqlite("dentaland.db")` umjesto
   `FakeStore.seeded(...)`; app.py više ne importuje SQLAlchemy/FakeStore.
4. `desktop/views/main_window.py` — doctor dropdown (popunjen iz
   `store.doctors()` ako postoji; FakeStore ga nema pa se preskače), na
   promjenu `store.set_doctor()` + refresh; uhvati `OverlapError` pri unosu.
5. `desktop/views/week_view.py` — `move_appointment_to_slot` čuva trajanje
   (`new_end = new_start + (appt.end - appt.start)`), uhvati `OverlapError`;
   import `SARAJEVO` ostaje iz fake_data, `Appointment`/`FakeStore` se
   zamjenjuju DTO/servisom.
6. `tests/test_services.py` — kreiranje, odbijanje preklapanja (uklj. termin
   duži od slota), pomjeranje uspješno/odbijeno, CANCELLED/COMPLETED/NO_SHOW
   ne blokiraju, drugi doktor ne blokira, seed.

**Šta NE dirati:** `src/dentaland/models.py`, `migrations/**`,
`desktop/fake_data.py`, `desktop/views/appointment_dialog.py`, `tests/test_gui/**`
(nije u allowed_paths — postojeći GUI testovi se ne mijenjaju).

**Plan verifikacije:**
- `pytest tests/test_services.py -v`
- `pytest tests/test_gui -v`
- `ruff check src/dentaland desktop tests`
- `grep -ri sqlalchemy desktop/views` (očekivano prazno)

**Rollback:** `git checkout -- <izmijenjeni>` + `git clean` novih fajlova unutar
worktree-a (sve necommittovano).

**Odbačene opcije:**
- Provjera preklapanja u WeekView (GUI) umjesto servisa — odbačeno: backend
  (servis) mora biti konačni autoritet; GUI `_appointments_by_cell` ima poznat
  bug (jedna ćelija po terminu) pa nije pouzdan.
- `phone/email/note` kao `str | None` u DTO — odbačeno: fake `Appointment` ima
  `str`, pa DTO normalizuje `None → ""` da GUI ostane isti.
- Seed logika u `app.py` inline — odbačeno: `ensure_seed_data`/`from_sqlite` u
  servisu drži app.py tankim i seed testabilnim.
