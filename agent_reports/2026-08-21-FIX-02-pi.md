# FIX-02 — Popraviti edit trajanja termina

## Task Contract

Izvor: `agent_reports/FIX-02-task-contract.md` (puni kontekst u
`docs/dentaland-desktop-korektivni-plan.md`, sekcija 2).

Cilj: u `AppointmentEditorDialog` edit mode, `_prefill()` ispravno
postavlja stvarno trajanje (`end - start`), ali bezuslovni poziv
`_apply_service_duration(self.service_combo.currentIndex())` odmah poslije
prepisuje to trajanje default trajanjem izabrane usluge. LOW risk; jedan
nezavisan reviewer (Claude).

## Root cause (potvrđen u kodu)

`desktop/views/dialogs/appointment_editor.py`, `__init__`:

- `self._prefill(appointment)` (edit mode) postavlja
  `duration_edit` na `end - start`;
- blok na kraju konstruktora:

```python
if self.service_combo.count():
    self._apply_service_duration(self.service_combo.currentIndex())
self.service_combo.currentIndexChanged.connect(self._apply_service_duration)
```

bezuslovni poziv `_apply_service_duration(...)` se izvršava i u edit modu i
prepisuje upravo prefillovano trajanje defaultom usluge.

## Fix

Minimalan, kako kontrakt predlaže — usloviti inicijalni poziv sa
`not is_edit`:

```python
# Podrazumijevano trajanje iz prve usluge; promjena usluge ga ažurira.
# U edit modu trajanje je već postavljeno iz _prefill() (end - start) i
# ne smije se odmah prepisati defaultom usluge.
if not is_edit and self.service_combo.count():
    self._apply_service_duration(self.service_combo.currentIndex())
self.service_combo.currentIndexChanged.connect(self._apply_service_duration)
```

`connect()` ostaje bezuslovan u oba moda — ručna promjena usluge i dalje
ažurira trajanje (postojeće ponašanje netaknuto). Nije korišten
alternativni `_suppress_duration_sync` flag jer jednostavan uslov rješava
problem.

   `test_edit_mode_promjena_usluge_azurira_trajanje` (prefill 90, promjena
   na uslugu default 45 → 45).

   `test_trajanje_se_predlaze_iz_usluge` (30 pa 60); nije mijenjan.

default je takođe 60, pa nije detektovao bug — zato novi test koristi
trajanje 90 (različito od defaulta).
